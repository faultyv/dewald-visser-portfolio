# Complete artwork collection · October 2026

The portfolio now prioritises the complete artwork collection. `full-artwork-audit.json` maps every distinct image in the twelve project folders to a gallery asset, with a reason for any source reference kept separate. Existing galleries are preserved and expanded, including identity variants, campaign collections, full website pages, product imagery and event documentation.

Every gallery item is rendered by default. Category filters are optional, and native lazy loading controls image requests as visitors scroll. All compositions preserve their original proportions. Original source files remain in Downloads.

Only unbranded purchased templates, stock photo references and third-party institutional logos are kept separate from authored artwork. Private contracts, named academic records and previously restricted internal guides require specific approval before full public disclosure.

Large PDFs retain every page and are split into clearly labelled parts when needed. Vector copies preserve extracted text; very large Illustrator pages use complete rendered web copies. Asset transfers are uploaded in resumable batches before the final code update.

## Complete collection policy

Keep every authored image and distinct variant accessible in its project. `All work` is the default gallery state; category buttons only filter the displayed collection. Images use their native proportions, with full-size access and lazy loading. Original source files in Downloads are never modified by the import.

Large print publications preserve all pages. Web copies are optimized and, where useful, divided into numbered parts with explicit page ranges. Exceptionally large Illustrator page exports use a complete rendered page for web viewing; the editable originals remain in Downloads. No page is cropped.

The annual report cover is displayed, while student results and confidential contract documents are held back pending permission. Four Illustrator files without PDF-compatible content remain in Downloads and require artwork exports; their warning pages are not portfolio artwork.

Uploads use a temporary cache branch with durable per-batch progress files in `profile-backups/`; production is only updated after validation.

`native-artwork-audit.json` also maps five Photoshop composites and nine SVG sources. Native vector artwork stays scalable; transparent white marks receive a contrasting UI canvas without changing their source files. `certificate-audit.json` records every file reviewed in the certificate folder and the safe public download chosen for it.
